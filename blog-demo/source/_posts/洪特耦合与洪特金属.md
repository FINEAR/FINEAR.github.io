> 承接上一篇《DMFT动力学平均场理论入门》。那篇结尾提到"洪特金属：由 Hund 耦合而非 Mott 机制驱动的坏金属行为"，只用一句话带过。这篇把它展开讲透：从原子物理的洪特规则出发，建立多轨道 Hubbard 模型与 Kanamori 相互作用，然后一步步说明 $J$ 到底做了什么、为什么它比 $U$ 更"阴险"、以及怎么在实验上认出洪特金属。

## 一、一个用 Mott 图像解释不了的现象

传统强关联的叙事很干净：判断一个体系关联强不强，看库仑排斥 $U$ 与带宽 $W$ 的比值。

- $U/W \ll 1$：弱关联，能带理论够用，准粒子权重 $Z \approx 1$；
- $U/W \gtrsim 1$：强关联，准粒子变重（$m^*/m = 1/Z$ 明显大于 1），直到发生 Mott 转变变成绝缘体。

但 2000 年代中后期，人们在一批材料上发现了不顺从这个剧本的行为：

- **钌氧化物**：$\mathrm{Sr_2RuO_4}$ 的 $4d$ 电子 $U$ 只有约 2~3 eV，$U/W$ 大概 0.3~0.5，按 Mott 图像应该是个挺"正常"的金属。可实测有效质量增强到 3~5 倍，比能带值重得多。
- **铁基超导体**：$\mathrm{LaFeAsO}$ 家族的母体是金属、不是 Mott 绝缘体，却表现出很差的金属性、很大的电阻率，以及跨越数百 K 的"相干—非相干"渡越。
- **$4d$ 与 $5d$ 化合物普遍如此**：这些体系的 $U$ 因轨道空间扩展而明显小于 $3d$ 体系，本来以为关联会更弱，结果经常比 $3d$ 体系还古怪。

把这些体系放在一起，共同点就浮现出来了：**它们都是多轨道体系，而且洪特耦合 $J$ 不小。**

真正的控制参数不只是 $U/W$，还有 $J$ —— 在某些填充下，$J$ 甚至比 $U$ 更能决定物理。这套"多轨道 + 洪特耦合"的组合催生了一个专门的名字：**洪特金属（Hund's metal）**。

## 二、原子物理的老朋友：洪特规则

洪特耦合 $J$ 不是新东西，它就是原子物理里洪特第一规则在多体哈密顿量中的化身。洪特规则（1925）说的是同一个原子中电子填充简并轨道时的定则：

1. **第一规则**：总自旋 $S$ 取最大，也就是电子尽量自旋平行；
2. **第二规则**：在 $S$ 最大的前提下，总轨道角动量 $L$ 取最大；
3. **第三规则**：前两条定下后，由自旋—轨道耦合决定总角动量 $J$：壳层未满一半时 $J = |L-S|$，超过一半时 $J = L+S$。

### 为什么自旋平行能量更低

第一规则的能量来源是**交换能**，本质上是库仑排斥与泡利原理的共同作用。想一个格点上的两个电子：

- 自旋**平行**时，总波函数必须反对称，于是空间部分必须**反对称**——两个电子互相回避，平均距离变大，库仑排斥能**降低**；
- 自旋**反平行**时，空间部分可以是对称的——两个电子允许靠得更近，库仑排斥能**升高**。

所以"自旋平行更省能量"并不是什么磁相互作用，而是**库仑排斥在泡利约束下被削弱**的结果。这个能量差的量级就是洪特耦合 $J$，典型值 $0.3 \sim 1\ \mathrm{eV}$。

先记住一个数：在下面要讲的 Kanamori 参数化里，同一格点上两个电子的**高自旋态比低自旋态低 $2J$**（第三节会给出推导）。这个 $2J$ 是后面所有现象的种子。

## 三、多轨道 Hubbard 模型与 Kanamori 相互作用

### 多轨道 Hubbard 模型

把上面两件事搬到晶格上。一般的多轨道 Hubbard 模型写成

$$H = \sum_{ij}\sum_{mm'}\sum_{\sigma} t^{mm'}_{ij}\, c^{\dagger}_{im\sigma} c_{jm'\sigma} + H_{\mathrm{int}} - \mu \sum_{im\sigma} n_{im\sigma}$$

- $m = 1,\dots,M$ 是轨道指标，例如 $t_{2g}$ 的 $d_{xy}$、$d_{yz}$、$d_{zx}$ 对应 $M=3$；
- 第一项是动能：电子在格点之间、**轨道之间**都能跳跃，$t^{mm'}_{ij}$ 同时携带晶格几何与轨道重叠的信息；
- $H_{\mathrm{int}}$ 是同一格点上的相互作用，多轨道里它的结构比单轨道丰富得多。

### Kanamori 相互作用

$H_{\mathrm{int}}$ 最常用的写法是 Kanamori 形式（1963）。它保留了自旋的 SU(2) 对称性与立方晶格对称性，最后只留下两个参数 $U$ 和 $J$：

$$H_{\mathrm{int}} = U\sum_m n_{m\uparrow}n_{m\downarrow} + U'\sum_{m\neq m'} n_{m\uparrow}n_{m'\downarrow} + (U'-J)\sum_{m<m'}\sum_{\sigma} n_{m\sigma}n_{m'\sigma} - J\sum_{m\neq m'} c^{\dagger}_{m\uparrow}c_{m\downarrow}c^{\dagger}_{m'\downarrow}c_{m'\uparrow} + J\sum_{m\neq m'} c^{\dagger}_{m\uparrow}c^{\dagger}_{m\downarrow}c_{m'\downarrow}c_{m'\uparrow}$$

五个项逐个看：

1. $\;U$：同一轨道、相反自旋的两个电子之间的库仑排斥；
2. $\;U'$：不同轨道、相反自旋的两个电子之间的库仑排斥；
3. $\;U'-J$：不同轨道、**相同自旋**的两个电子之间的排斥——注意它比 $U'$ 少了 $J$，这正是洪特耦合的直接体现；
4. $\;-J$：自旋翻转过程——一个轨道里电子翻自旋，同时另一个轨道也翻，保持总自旋守恒；
5. $\;+J$：配对跳跃——同一轨道上的两个电子一起搬到另一个轨道。

**立方对称下有一个重要关系**（来自 $t_{2g}$ 或 $e_g$ 轨道波函数的角度积分）：

$$U' = U - 2J$$

于是独立参数只剩两个：$U$ 和 $J$；第 3 项的系数化为 $U - 3J$。把三项两体排斥整理成一张表：

| 情形 | 相互作用能 |
| --- | --- |
| 同轨道、相反自旋 | $U$ |
| 异轨道、相反自旋 | $U - 2J$ |
| 异轨道、平行自旋 | $U - 3J$ |

**这张表就是整个洪特物理的起点**：同样是两个电子，自旋平行时它们之间的排斥能比反平行时**低 $J$**。

### 原子极限：高自旋比低自旋低 2J

在一个格点上放两个电子，分处不同轨道 $m \neq m'$。四个两电子态中，对角能量是 $U'$（反平行）或 $U'-J$（平行），而非对角元来自第 4 项自旋翻转：

$$\langle m\!\uparrow, m'\!\downarrow | H_{\mathrm{int}} | m\!\downarrow, m'\!\uparrow \rangle = -J$$

在 $\{|m\!\uparrow, m'\!\downarrow\rangle,\ |m\!\downarrow, m'\!\uparrow\rangle\}$ 这个二维子空间里，哈密顿量是

$$H_{2\times 2} = \begin{pmatrix} U' & -J \\ -J & U' \end{pmatrix}$$

本征值是 $U' \mp J$，对应两个态：

- **高自旋（三重态，$S=1$）**：$E_{\mathrm{HS}} = U' - J = U - 3J$
- **低自旋（单重态，$S=0$）**：$E_{\mathrm{LS}} = U' + J = U - J$

$$\Delta E = E_{\mathrm{LS}} - E_{\mathrm{HS}} = 2J$$

**洪特第一规则就是从这里来的**：原子极限下，同一格点上的电子倾向于自旋平行，能量上占便宜 $2J$。$J$ 越大，局域高自旋态越稳。

## 四、洪特耦合到底改变了什么

把它放进晶格。$J$ 的作用可以拆成四条，逐条看。

### 1. 它让局域磁矩变大

$2J$ 的高低自旋劈裂意味着：即使在 $U$ 并不大的金属里，格点上的电子也会**主动选择高自旋组态**。以 $M=3$、每格点 2 个电子（$n=2$）为例，高自旋态是 $S=1$，有效磁矩

$$\mu_{\mathrm{eff}} = g\sqrt{S(S+1)}\,\mu_B = 2\sqrt{2}\,\mu_B \approx 2.83\,\mu_B$$

比自旋 $1/2$ 的 $1.73\,\mu_B$ 大得多。这是洪特金属在磁化率上的第一个特征。

### 2. 大的局域磁矩很难被屏蔽

在金属里，局域磁矩会被导电子通过近藤效应屏蔽，形成一个相干的费米液体，特征温度是近藤温度 $T_K$。问题在于：$T_K$ 对磁矩大小极其敏感——**屏蔽一个 $S=1$ 的磁矩比屏蔽 $S=1/2$ 困难得多**，$T_K$ 会被指数级压低。

对洪特金属，起作用的能量尺度不是 $U$ 而是 $J$，而 $T_K$ 随 $J$ 是**指数衰减**的（$J$ 出现在指数上的分母里）。所以哪怕 $J$ 只有零点几 eV，$T_K$ 也可能掉到几十 K 甚至更低。

**后果**：在 $T \gg T_K$ 的温区——也正是室温附近——你看到的不是费米液体，而是**一堆缓慢涨落的局域磁矩在散射电子**。这就是"坏金属"。

### 3. 它抑制电子的相干跳跃

这是最直观的图像。考虑 $n=2$、$M=3$ 的格点，上面已经有两个电子（高自旋，$S=1$）。现在让一个电子从邻居跳过来，它只有两条路：

- 挤进已被占据的轨道，付出 $U$，代价很大；
- 进入空轨道，但它的自旋必须和已有的局域磁矩**对齐**，否则要额外付出约 $J$ 的能量。

也就是说，**洪特耦合把自旋自由度绑在了轨道占据上，电子无法自由地相干跳跃**：每次跳跃都要重新安排自旋组态，能量代价正比于 $J$。这直接压低了电子的有效动能，等价地表现为**带宽变窄、有效质量增大**。铁基超导体里，这个机制被称为"**动能受挫**（kinetic frustration）"。

由此得到一个粗略判据：洪特耦合要主导物理，需要 $J$ 与有效动能尺度可比，

$$J \gtrsim W_{\mathrm{eff}}$$

对 $4d$、$5d$ 体系，$W$ 因轨道扩展而变小、$U$ 也变小，但 $J$ 衰减得慢得多，所以 $J/W$ 反而不小——这正是**钌、铑、铱的化合物比铁、钴、镍的化合物更容易成为洪特金属**的原因。

### 4. 它把不同轨道的自旋绑在一起

$J$ 只作用在不同轨道之间（$m \neq m'$），所以它对**轨道间**的自旋关联特别有效：不同轨道的电子倾向形成总自旋最大的一致排列。这带来一个很重要的副作用——**轨道选择性**。

洪特耦合只在有多个轨道被占据时才起作用，于是填充数 $n$ 与轨道简并度变得关键：

- 某个轨道几乎空着或几乎满着时，$J$ 几乎不起作用；
- $J$ 大到足以让某个轨道"退出"相干（它的电子被局域化），而剩余轨道仍保持金属性时，就出现**轨道选择性 Mott 转变**（OSMT）。

## 五、洪特金属的判据

把上面的讨论综合起来，洪特金属大致落在这片区域里：

| 条件 | 说明 |
| --- | --- |
| 多个简并或近简并轨道 | 单轨道体系没有洪特物理 |
| 整数填充、且倾向高自旋 | 例如 $t_{2g}$ 的 $n=2$ 或 $n=4$，都对应 $S=1$ |
| $J/W$ 不算小 | 经验上约 $J/W \gtrsim 0.1$ |
| $U/W$ 中等 | 不必大到已经发生 Mott 转变 |

### "两面神"效应：J 的作用会随填充反转

一个反直觉但很重要的结果：$J$ 对 Mott 转变的影响**不是单调的**。

- 在**半满**（每个轨道恰好一个电子）情形，$J$ 反而**抬高** Mott 转变的临界 $U$，让金属更"结实"；
- 在**偏离半满**、体系又倾向形成高自旋局域矩的填充附近（比如三轨道 $n=2$），$J$ 会**显著增强**关联效应，把体系推向坏金属甚至 Mott 绝缘体。

同一个 $J$，在两个填充下作用相反，因此被称为"**两面神**（Janus-faced）"。这也解释了为什么洪特金属往往出现在**非半满**的填充上。

半满与非半满的差别可以用动能来理解：

- 半满时每个轨道被单占据，电子可以在轨道间"换位"而不破坏自旋结构，有效动能受 $J$ 影响较小；
- 非半满时格点上已有电子，跳进来的电子必须绕过已有的局域矩，Pauli 阻塞与洪特对齐形成双重约束，动能被大幅抑制。

## 六、实验上怎么认出洪特金属

洪特金属有一组相当有辨识度的实验指纹，和经典的 Mott 型关联有明显区别：

| 观测量 | 洪特金属的表现 | 与 Mott 型的区别 |
| --- | --- | --- |
| 磁化率 $\chi(T)$ | 高温居里—魏斯行为，有效磁矩接近高自旋值 | 磁矩大，源自洪特高自旋组态 |
| 电阻率 $\rho(T)$ | 很宽温区呈 $T$ 线性（坏金属），低温才回到 $T^2$ | $T$ 线性区极宽 |
| 比热系数 $\gamma$ | 显著增强 | 与质量增强一致 |
| 有效质量 $m^*/m$ | 增强 3~10 倍 | 但 $U/W$ 并不大 |
| Kadowaki-Woods 比 $A/\gamma^2$ | 明显偏离普适值 | 这种"违反"本身就是指纹 |
| 光电导 $\sigma(\omega)$ | Drude 权重被压低，中红外出现宽吸收峰 | 反映非相干散射 |
| ARPES | 带宽重整，色散出现扭折 | 对应自能虚部的大尺度结构 |
| 相干—非相干渡越温度 $T^*$ | 可达数百 K，与 $J$ 相关 | 与 $U/W$ 关系不直接 |

其中**"$T$ 线性电阻 + 居里—魏斯磁化率 + 低温费米液体"三段式**是最典型的洪特金属签名。

## 七、真实材料举例

### 钌氧化物：教科书级的案例

$\mathrm{Sr_2RuO_4}$ 的 Ru$^{4+}$ 是 $4d^4$，三个 $t_{2g}$ 轨道上共 4 个电子（每轨道约 1.33 个）。DFT+DMFT 给出的有效质量增强与实测比热、de Haas–van Alphen 结果符合得很好，而这个增强**主要来自洪特耦合，而不是 $U$**。它同时表现出清晰的相干—非相干渡越：低温是相干费米液体，温度升到几十到上百 K 后进入非相干区，电阻率呈 $T$ 线性。

### 铁基超导体：动能受挫

铁基母体 $\mathrm{LaFeAsO}$ 的 Fe 是 $3d^6$，$U \approx 4\sim 5\ \mathrm{eV}$、$J \approx 0.6\sim 0.9\ \mathrm{eV}$。$U/W$ 并不大，但 DFT+DMFT 显示它落在洪特金属区：局域磁矩偏大、相干温度低、谱权重向中红外转移。这被认为是铁基超导"母体是金属而非 Mott 绝缘体"的关键。

### 其他体系

- 钌基钙钛矿 $\mathrm{SrRuO_3}$、$\mathrm{CaRuO_3}$；
- $5d$ 铱氧化物（$\mathrm{Sr_2IrO_4}$ 等），那里 $U$ 小、$J$ 相对更强，还要与强自旋—轨道耦合竞争；
- 部分钒、铬的硫族化合物与层状范德瓦尔斯磁体——这类体系的 $d$ 轨道带宽窄、轨道简并度高，正是洪特物理最容易登场的地方。

## 八、与 Mott 物理的对照

| 维度 | Mott 型关联 | 洪特型关联 |
| --- | --- | --- |
| 控制参数 | $U/W$ | $J/W$，以及填充与轨道简并度 |
| 物理起源 | 电荷排斥 | 交换能（泡利约束下的库仑） |
| 低能自由度 | 电荷 | 自旋（大的局域磁矩） |
| 典型磁矩 | 小，$S=1/2$ | 大，$S=1$ 或更大 |
| 相干温度 | 由 $U$、$W$ 共同决定 | 随 $J$ 指数压低 |
| 走向绝缘的路径 | 直接 Mott 转变 | 先坏金属，再轨道选择性局域化 |
| 代表材料 | $\mathrm{V_2O_3}$、铜氧化物母体、$\mathrm{NiO}$ | 钌氧化物、铁基超导体 |

## 九、一句话总结

> 洪特耦合 $J$ 是交换能在多轨道体系里的化身：它让同一格点的电子倾向自旋平行（能量上占便宜 $2J$），于是产生大而缓慢的局域磁矩。这些大磁矩既难被近藤屏蔽，又通过泡利阻塞与自旋对齐抑制电子的相干跳跃——结果是**在 $U$ 并不大的情况下就把金属变成了坏金属**。这就是洪特金属：控制参数不是 $U/W$，而是 $J/W$。
